# Change Request

A Change Request is used when a modification affects an accepted decision or requires controlling a new evolution.

## STATUS

```text
PROPOSED
ANALYZING
AWAITING_DECISION
APPROVED
IMPLEMENTING
VALIDATING
ACCEPTED
REJECTED
CANCELLED
BLOCKED
```
